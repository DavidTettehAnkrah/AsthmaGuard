# Intelligent Wrist-Wearable Asthma Prediction System - Web Dashboard

A production-ready web application for managing user accounts and wrist-wearable device registration for an intelligent asthma prediction system. Built for a university final year project.

## 🎯 Project Overview

This web application serves as a companion dashboard for the wrist-wearable asthma prediction device. It provides:

- **User Management**: Secure registration and authentication
- **Device Registration**: Register and manage ESP32-based wearable devices
- **Profile Management**: Store medical information and emergency contacts
- **Secure API**: JWT-based authentication with protected routes

## 🛠️ Tech Stack

- **Frontend**: Next.js 15 (App Router), TypeScript, Tailwind CSS, shadcn/ui
- **Backend**: Next.js API Routes
- **Database**: MongoDB with Mongoose ODM
- **Authentication**: JWT tokens with httpOnly cookies
- **Deployment**: Docker, Vercel-ready

## 📋 Prerequisites

- Node.js 18+ and npm 9+
- MongoDB 7.0+ (local or MongoDB Atlas)
- Docker and Docker Compose (optional, for containerized deployment)
